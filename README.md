# Interactive Differential Equations — Student Edition

Student course materials for Differential Equations, Chapters 1–9.

## What is included

- **44 interactive lecture notebooks**
- **44 student homework notebooks**
- Course index and student guide
- Local Jupyter/Cursor/VS Code environment files


## Start here

Open `Course_Index.ipynb`.

### JupyterLab on macOS

Double-click `START_HERE.command`, or run:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
jupyter lab Course_Index.ipynb
```

### Windows

Double-click `START_HERE.bat`.

### Cursor or VS Code

1. Open this whole folder.
2. Install the Python and Jupyter extensions if needed.
3. Create/select the `.venv` environment.
4. Open `Course_Index.ipynb`.
5. Choose the `.venv` Python kernel.

## Classroom workflow

Work through the lecture notebooks one cell at a time. At each **Classroom Checkpoint**, stop and solve the question before class discussion continues.
